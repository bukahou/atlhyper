## 第一组：权限声明与渲染（`fix/permission-and-rendering`，合入 `481274e`）

- 路由按（方法，路径）声明权限；未声明的方法由 ServeMux 返回 405 — ✅（`dcb2d67`）
  - `routes_test` 遍历全部路由声明，新增路由漏声明时测试失败
  - 新增 `slo.manage`（2 级）；AI Provider 新建与 AI 设置修改归入 `ai.settings.write`
- GitHub App 安装回调需 `github.manage`，并校验安装归属 — ✅（`c64b4df`）
- 前端断开 GitHub 改调 `DELETE /api/github/disconnect` — ✅（`1f052b9`）
- Pod 日志查看器改为纯文本渲染，搜索高亮由 React 渲染 — ✅（`c41ee52`）
- AI 工具按「谁会看到结果」授权；会话只对创建者开放 — ✅（`db26c19`）
- AI 的 GitHub 工具限定仓库范围；读到的 Secret 清单值脱敏 — ✅（`438bbb6`）
- 通知渠道凭据只写不回显；测试发送并入网关，移除独立 tester 服务 — ✅（`bcf0743`）
- 审计请求体按 JSON 解析后脱敏 — ✅（`3e35903`）

## 第二组：快照字段与指令目标（`fix/resource-fields-and-name-validation`，合入 `89aa425`）

- 快照不再上报、Master 也不保留「整份清单副本」类注解 — ✅（`9815f0b`、`742d7a3`）
  - 判定分三层：已知键名、键名后缀、值的内容
  - `ClusterSnapshot` 里每个 `Annotations` 字段的覆盖由反射测试守护
- 移除无调用方的 `GET /api/v2/clusters/{id}`，连同服务方法、模型类型与文档 — ✅（`c6c8957`）
- 指令目标的命名空间与名字按 K8s 命名规则校验，Master 创建时与 Agent 执行前各一次 — ✅（`4c710e1`）
- 图表与拓扑图的提示框统一用 `lib/safe-html` 模板拼接；守卫测试改用 TypeScript 语法树 — ✅（`ae2fa15`）

## 行为变化

- 1 级用户在 AI 对话中可用的工具按其网关权限收窄；AI 设置写入需 3 级
- 通知页不再显示已保存的渠道凭据，留空表示保持不变
- 工作负载详情的注解页不再显示 `last-applied-configuration` 一类注解
- `GET /api/v2/clusters/{id}` 返回 404；资源数据走各自的列表 / 详情接口
- 名字不符合 K8s 命名规则的指令在创建时被拒绝
